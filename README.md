#cegep-omnivox-archiver

Ce projet a pour objectif d’archiver localement les documents Omnivox associés à l’ensemble des cours d’un étudiant.

Le code a été rendu public afin de permettre aux étudiants de télécharger et de conserver plus facilement leurs documents de cours à des fins personnelles.

##Avertissement

Ce projet est fourni tel quel, sans garantie. Le code peut contenir des bogues ou ne pas fonctionner correctement dans certains cas.

##Documentation

Aucune documentation détaillée n’est fournie pour le moment. L’utilisateur est responsable de comprendre le fonctionnement du code et de l’adapter à ses besoins.
